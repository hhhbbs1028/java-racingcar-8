# java-racingcar-precourse
## 자동차 경주
### 기능 요구 사항
- n대의 자동차는 전진 또는 정지
- 각 자동차에 이름 부여 가능
  - 이름은 쉼표를 기준으로 구분
  - 이름은 5자 이하만 가능
- 이동 횟수에 대한 사용자 입력
- 0-9 무작위 값이 4 이상일 경우 전진
    - 전진 자동차 출력 시 이름 같이 출력
- 우승자 출력
  - 우승자가 여러 명일 경우 쉼표로 구분
- 잘못된 값 입력 시 <code>IllegalArgumentException</code> 발생 후 종료

### 입출력 예시
```java
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```
- 입력 : 자동차 이름, 시도 횟수
- 출력 : 횟수 별 실행 결과, 최종 우승자
